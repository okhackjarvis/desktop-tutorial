# シルバーウィーク2026・大阪発で使えるJR乗り放題きっぷ

- 調査日: 2026-09-18
- 条件: 大阪発 / 9/19(土)出発 / 2〜3泊 / 行き先不問 / 宿は当日調達 / 破格重視

---

## 1. 結論

**全国のJR乗り放題は、この連休には存在しません。** 期間の谷間に落ちています。

| きっぷ | 2026年の期間 | 9/19-23は |
|---|---|---|
| 青春18きっぷ（夏） | 利用 7/18 〜 **9/8** | **終了済み** |
| 秋の乗り放題パス | 発売 9/18〜10/16 / 利用 **10/3 〜 10/18** | **まだ始まらない** |

秋の乗り放題パスは、発売がまさに今日9/18から始まりますが、使えるのは10月3日からです。
シルバーウィークは、18きっぷが終わった後・秋パスが始まる前の、ちょうど空白期間にあたります。

**代わりに使えるのが「JR西日本QR2dayパス」です。関西圏限定ですが、当日でも買えます。**

### 乗れる列車

- **普通列車（新快速・快速を含む）の普通車自由席のみ**
- 特急、新快速Aシート、快速うれしート、普通車指定席は**別途料金で利用可**

## 3. 元は取れるか

区間運賃（片道）との比較:

| 区間 | 片道運賃 |
|---|---|
| 長浜 〜 姫路 | 3,740円 |
| 京都 〜 姫路 | 2,210円 |
| 姫路 〜 奈良 | 2,210円 |
| 三ノ宮 〜 和歌山 | 1,880円 |
| 京都 〜 関西空港 | 1,860円 |
| 大阪 〜 姫路 | 1,460円 |
| 京都 〜 長浜 | 1,340円 |
| 大阪 〜 和歌山 | 1,300円 |
| 大阪 〜 奈良 | 840円 |

**判定**

- 近場をちょろっと動くだけだと**元が取れません**（大阪〜奈良往復で1,680円）
- **端から端まで動けば一発で元が取れます**。長浜〜姫路の片道だけで3,740円
- 2日で「大阪→姫路→（泊）→姫路→奈良→大阪」のように大きく回すなら余裕で黒字

## 4. 2〜3泊をどう組むか

パスは**2日間**なので、3泊すると足が出ます。

| 案 | 費用 | 内容 |
|---|---|---|
| A | 4,000円 | 9/19-20 にパス、9/21は実費で帰る |
| B | 8,000円 | 2枚買って 9/19-20 と 9/21-22 をカバー（実質4日間） |

Bでも1人8,000円。大阪→能登の在来線片道（5,040円）を考えると、かなり安く動けます。
