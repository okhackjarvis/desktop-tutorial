# WILL

科学で鍛える筋トレ記録アプリ。

研究に基づいて、目的に合わせたトレーニングの目安と弱点を教えてくれる筋トレ記録 Web アプリ（PWA）です。ビルド不要の HTML / CSS / JavaScript だけで動きます。ログインすると記録がクラウド（Supabase）に保存され、スマホと PC で同じ記録を使えます。ログインしないときは端末内にだけ保存されます。

## できること

- **初回設定**：目的（筋肥大・筋力・減量・健康維持）、トレーニング歴、場所、体重、身長、性別（任意）
- **今日のメニュー**：週の日数から分け方（全身／上半身・下半身／押す・引く・脚）を決め、レベルに合わせて種目を提案（初心者はマシン中心、中級者以上はフリーウェイトや自分で追加した種目を優先）。種目の入れ替え・固定、分け方・選び方・種目数は設定で変更可
- **今日の目標（漸進性過負荷）**：前回の全セットから今日の各セットの重量・回数を決める（全セットが目標回数の上限に届いたら重量を上げ、回数を下限に戻す。届かなければ同じ重量で+1回）
- **休憩タイマー**：円形ダイヤル、一時停止・再開、±15秒、終了の音とバイブ、残り20秒の予告音、画面をつけたまま、種目ごとの休憩時間（最後のセットのあとは1分30秒）
- **アップ・左右別・フォームのポイント・メモ**：1種目目の前にアップ（本番の約60%、数えない）、片手の種目は左右別に記録、種目ごとの「気をつけること」、種目のメモとその日のトレーニングメモ、今週・連続・通算の日数
- **記録**：種目は入力で絞り込める（ひらがな・部位名でも検索、候補にない種目はその場で追加）。重量・回数・余力（あと何回できたか）。前回の記録から次回の重量と回数を提案（ダブルプログレッション）。目的に合わせた休憩タイマー。今日の調子
- **分析**：部位ごとの週のセット数と目安の比較、弱点と鍛える種目の提案、頻度、追い込み度と回数のチェック、伸び悩み種目の検出。各項目に根拠となる論文を表示
- **進捗**：種目ごとのグラフ（最大重量・推定1RM・総挙上量）、今週のまとめ画像（SNS シェア用）、履歴
- **体**：体重の推移と週の変化率のチェック、たんぱく質の目安、サイズの記録、体の写真の比較（`photo.html`）、生理周期の記録（任意）
- **設定**：プロフィール、伸ばしたい部位・避けたい部位、種目と鍛える部位の登録、データのエクスポート／インポート
- **ログイン・同期**：メールアドレスとパスワードで登録・ログイン、パスワードの再設定、記録の自動同期（保存のたびにクラウドへ、アプリに戻ったときに他の端末の更新を取り込み）、ログアウト、アカウント削除。ログインせずに使うこともできる
- **PWA**：ホーム画面に追加でき、オフラインでも動作

AI による食事アドバイスは準備中です（サーバーと AI の利用料が必要なため、有料プランでの提供を予定）。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `js/app.js` | 画面の処理 |
| `js/science.js` | 研究に基づく目安・分析ロジック（画面に依存しない関数） |
| `photo.html` / `photo.js` / `photo.css` | 体の写真の撮影と比較 |
| `js/icons.js` | アイコン（Lucide）とロゴ |
| `js/illustrations.js` | 記録がない画面のイラスト |
| `js/tips.js` | 種目ごとの「気をつけること」 |
| `js/cloud.js` / `js/config.js` | ログインとクラウド同期（Supabase）。`config.js` に接続先を書く |
| `supabase/schema.sql` | Supabase に作る表と権限 |
| `vendor/` | ログイン用ライブラリ（supabase-js 2.45.4。npm の公式版をそのまま置いたもの、MIT License） |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA（オフライン対応・ホーム画面のアイコン） |

アプリを更新したときは、`sw.js` の `CACHE` の名前（`will-v13` など）を変えると、利用者の端末のキャッシュが入れ替わります。

## ログインの準備

`docs/SUPABASE_SETUP.md` を見てください。`js/config.js` が空のときは、ログイン画面は出ず、これまでどおり端末の中だけで動きます。

## ローカルで動かす

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 注意

アドバイスは研究に基づく一般的な目安で、医療的な助言ではありません。
